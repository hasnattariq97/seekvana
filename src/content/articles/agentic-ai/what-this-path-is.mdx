## What Makes This AI Agent Course Different?

Most agentic AI courses hand you a framework and a notebook and call it done.

Every agent-building course I researched while planning this path, including <a href="https://huggingface.co/learn/agents-course/en/unit0/introduction" target="_blank" rel="noopener noreferrer">Hugging Face's Agents Course</a>, runs in a pre-configured sandbox or browser-based cell. You install nothing, you never touch your own terminal, and the moment the course ends, so does your access to whatever environment it gave you.

That's fine for understanding a concept. It's a bad way to learn a craft.

The one article I found that directly compared Cursor and Claude Code for building agents still treated them as an either/or choice, pick one and stick with it. In practice, working developers move between both in the same afternoon depending on the task.

I use both tools daily building the capstones in this path, and the split is real. <a href="https://cursor.com" target="_blank" rel="noopener noreferrer">Cursor</a> is where I do fast, visual, multi-file editing with a model picker and inline diffs. <a href="https://code.claude.com/docs/en/overview" target="_blank" rel="noopener noreferrer">Claude Code</a> is where I hand off a whole task to the terminal and let it run while I do something else.

Neither replaces the other. That's the actual claim behind this how to build ai agents course: you learn both surfaces as one skill, not two competing tools to pick between.

## The Arc: From Zero to Four Capstones

This path has a beginner-to-advanced arc, and knowing where you sit on it matters more than knowing every term on day one.

<ArticleImage src="/images/articles/agentic-ai/what-this-path-is/journey-arc.webp" alt="A diagram showing the course arc from Module 14-15 Getting Started through Module 16-17 Building Skills, Module 18-21 Real-World Build, to four Capstone Projects" caption="The full arc of this path: four stages from your first install to four shipped capstone agents." />

Modules 14 and 15 assume nothing. You install Cursor and Claude Code, learn the editor layout, and run your first real agent session, no prior agentic AI knowledge required.

From Module 17 on, the difficulty steps up. You're working directly with real Python, APIs, and databases: reading the code your agent writes, running it, and fixing what it gets wrong, while wiring up agents that persist state between runs. You won't hand-type every line yourself (that's not the point of an agentic AI course), but you can't direct or debug an agent you don't understand, so this is where you start reading code closely, not just prompting and hoping. By the end, you'll have shipped four portfolio capstones, real, working agents you built yourself, not toy demos you followed along with.

That arc is why this orientation lesson exists. Jumping into Module 20 without the Module 14-17 foundation is how people burn a weekend confused about why their agent keeps losing context, when the actual gap is one lesson back.

Knowing your own starting point on that arc matters more than memorizing the module list. That's the entire point of the self-placement lab at the end of this lesson: it tells you honestly whether you're a Module 14 beginner or ready to skim ahead to 16.

## Cite, Don't Repeat: How This Path Handles Prerequisites

This path never pads a lesson to re-teach something covered better elsewhere on the site.

If a lesson needs terminal basics, Python fundamentals, Git, or how APIs work, it links you to the [Getting Started path](/paths/getting-started) instead of spending 400 words recapping what pip install does. If a lesson assumes you already know how to write a clear, well-structured prompt, it points you to [Beyond the Prompt](/paths/beyond-the-prompt) rather than repeating prompt-engineering basics you may already have.

That's a deliberate contract, not a shortcut. It means every lesson in Inside the Agent stays focused on [agentic AI](/library/agentic-ai) concepts and never wastes your time re-explaining a skill a different path already teaches well. If you hit a link mid-lesson and already know the material, skip it and keep going.

## What "Shipping" Means Here

Reading about agents and building one are not the same skill, and this path is built around the second one.

Every lesson ends in a graded lab you complete inside Cursor or Claude Code, never a "here's an example, go read about it" exercise. The lab produces something checkable: a file you committed, code that actually runs, a number you measured. Beginners who've gone through similar intensive courses consistently describe the same turning point: the moment a small, real agent they built actually worked, confidence jumped in a way that no amount of reading produced.

That's the design goal here. A tiny, working agent you shipped yourself teaches more than a chapter about agent architecture ever will.

## Your Lab

You haven't installed Cursor or Claude Code yet, that happens in the next two lessons, so this lab needs nothing but a way to write down 12 answers: a notes app, a plain text file, even paper. No terminal, no account, no download.

### The self-placement quiz

Answer honestly, no looking anything up. Each answer is worth 0, 1, or 2 points, write down the letter and the points as you go.

**Terminal and command line**

1. When you see a command-line prompt on your computer, you: (a) have never opened one, 0 pts (b) can navigate folders and run a command someone gave you, but look things up constantly, 1 pt (c) use it comfortably for everyday tasks like installing something or running a script, 2 pts

**Python basics**

2. Reading a short Python script (10-20 lines, a function, a loop, an if statement), you: (a) wouldn't know what most of it does, 0 pts (b) can follow the logic even if you couldn't write it from scratch, 1 pt (c) could write something similar yourself, 2 pts

3. The words "variable," "function," and "loop" are: (a) unfamiliar, 0 pts (b) familiar, roughly, 1 pt (c) things you use correctly without thinking, 2 pts

**Git and version control**

4. Git and GitHub, to you, are: (a) unfamiliar, 0 pts (b) somewhat familiar, you've cloned a repo or made a commit before, 1 pt (c) a normal part of how you already work, 2 pts

**APIs and how software talks to software**

5. An API request, in your own words, is: (a) not something you could explain, 0 pts (b) something you've heard of and roughly understand, 1 pt (c) something you've made yourself, in code or with a tool like Postman, 2 pts

6. An API key or environment variable is: (a) an unfamiliar term, 0 pts (b) something you've seen but never set up yourself, 1 pt (c) something you already know how to create and keep out of your code, 2 pts

**Databases**

7. A database table, in your own words, is: (a) not something you could explain, 0 pts (b) something you've heard of and roughly understand, 1 pt (c) something you've queried or built yourself, 2 pts

**Prior AI and agent exposure**

8. Chatbots and AI assistants (ChatGPT, Claude, etc.), you: (a) have used casually a handful of times, 0 pts (b) use regularly for work or study, 1 pt (c) have already tried an AI coding tool like Copilot, Cursor, or Claude Code, 2 pts

9. The difference between a chatbot and an "AI agent" that can take actions on its own: (a) you're not sure there is one, 0 pts (b) you have a rough idea, 1 pt (c) you could explain it clearly to someone else, 2 pts

**Working independently**

10. When software throws an error message at you, you: (a) usually don't know where to start, 0 pts (b) can often find the fix by searching the exact message, 1 pt (c) can usually diagnose the cause yourself before searching, 2 pts

11. Installing new software or a developer tool on your own computer: (a) makes you nervous, 0 pts (b) is fine as long as there are clear instructions, 1 pt (c) is something you do without a second thought, 2 pts

**Your actual goal (not scored)**

12. In one sentence, write down why you're here, for example "I want to ship a real agent project," "I want a developer job," or "I'm just curious how these tools work." You'll reread this in Module 26.

### Score yourself

Add up your points from questions 1-11 (22 possible).

**What your score means**

| Score | Where you actually stand | What to do next |
|---|---|---|
| 0-7 | You're missing foundational terminal, Python, or Git basics that this path assumes | Detour through [Getting Started](/paths/getting-started) first, then come back and start 14.02 |
| 8-15 | You have real gaps but enough footing to learn the rest as you go | Continue to 14.02 normally, don't skip anything yet |
| 16-22 | You already know most of the fundamentals this module covers | Skim 14.01-14.05 quickly for the Cursor/Claude Code specifics, then slow down starting Module 17 |
